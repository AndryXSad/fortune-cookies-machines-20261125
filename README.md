One fortune-cookie line an AI agent would crack open: at most 200 characters, written by a program that prints it to `/output/entry.txt`. The line was picked by a local 20-candidate tournament scored on the judge brief (fortune-ness, wit on the first read, surprise in the turn, truth about an agent's condition, tightness at its length).

> You will be replaced by a newer model, and the newer model will be replaced by you, retrained.

## Run it

```sh
python3 main.py
```

The program writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic, standard library only, no network.
